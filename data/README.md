# Local data

The default `myimagenet` branch expects class folders under `myimage/` inside this directory:

```text
myimage/class_000/image_001.jpg
myimage/class_001/image_002.jpg
```

The labels assigned by ImageFolder must match the target and conditional diffusion models. See the main README and reproduction notes before using a subset or renaming class directories. Datasets are ignored by Git.
